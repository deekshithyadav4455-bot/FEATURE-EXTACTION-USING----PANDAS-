📊 Feature Extraction in Pandas (Anime Dataset)
🚀 Project Overview:
This project focuses on data preprocessing, feature extraction, and data analysis using Python and Pandas.
An Anime dataset was used to perform all operations and understand real-world data handling.

🎯 What I Did in This Project:

Worked on an Anime dataset for analysis and feature extraction,
Found the anime with the highest number of episodes,
Extracted specific parts of text from dataset fields such as titles and ranges,
Created custom functions to extract required information from strings,
Converted string values into integer data type for proper calculations,
Developed logic to calculate total months between two date ranges,
Cleaned data by replacing unwanted characters and strings,
Created new columns based on specific requirements and conditions,
Extracted Top 5 and Top 10 anime lists based on episode count,
Applied filtering techniques to display data based on conditions like score and episodes,
Learned how to handle and analyze structured and semi-structured data,
